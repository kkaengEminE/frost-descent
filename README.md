# 돌아보지 마 — 얼음 지옥

Three.js 기반 1인칭 미로 탈출 게임. 모든 게임 모델과 환경은 절차적 3D geometry이며 Three.js는 로컬에 포함되어 있습니다.

## 실행

`python3 -m http.server 4173 --directory dist`

http://localhost:4173 에서 플레이합니다. 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

WASD 이동, 마우스 또는 방향키 시선, Space 점프, Shift 달리기, E 상호작용, Q 에울 부르기, Esc 일시정지. 터치 조작도 지원합니다.

5개 층, 이동 경로를 따라오는 동료, 시선에 반응하는 펭귄, 빙하 틈, 이글루 쉼터, 사다리, 도입/결말, 실패 후 층별 재시작이 포함됩니다. 설정과 도착한 층은 기기 로컬 저장소에 저장합니다.
